# M5 source dataset

RetailOps AI uses the **M5 Forecasting - Accuracy** competition dataset as its initial retail source.

## Why M5

M5 provides the core grain needed for the future forecasting use case: daily item-level sales by store, plus weekly prices and calendar/event information.

The V1 source contract uses three files:

- `calendar.csv`
- `sell_prices.csv`
- `sales_train_evaluation.csv`

`sample_submission.csv` and `sales_train_validation.csv` are competition-specific files and are not required by the RetailOps AI V1 ingestion path.

## Access

The dataset is hosted on Kaggle under the `m5-forecasting-accuracy` competition. Kaggle requires a user account, acceptance of the competition rules, and API authentication before downloading the files.

Never commit Kaggle credentials, `kaggle.json`, downloaded CSV files, or the competition ZIP archive to this repository.

## Download

After configuring Kaggle authentication locally, run:

```bash
chmod +x scripts/download_m5.sh scripts/validate_m5.sh
./scripts/download_m5.sh
```

The script downloads the competition archive into `data/raw/m5/`, extracts it locally, and validates the three files required by V1.

## Validate an existing download

```bash
./scripts/validate_m5.sh
```

Validation at this milestone checks only the **source contract**: the required files must exist and must not be empty. Schema and content-level checks are introduced in the ingestion milestone.

## Raw-data policy

The local `data/` directory is Git-ignored. In the cloud pipeline, these original files will later be copied unchanged to the GCS landing zone before any transformation is performed.
